Sonify for Graphs
----------------------------------------------------------------------------------------------------
SonifyGraphs is a website that can display data in various types of graphs as well as sonify data 
into a sound file. This allows users with visual impairment to also enjoy the powerful data 
representation that graphs allow. Accessibility is our first priority, and this is shown in the 
amount of additional accessibility features in our product.

Instructions to run website:
1. Download the zip files and unzip onto your computer.  
2. Open the folder in file explorer to view the html files. 
3. Select and open the index.html file in your browser of choice to start using the
   application. 
4. Once the html file is open, choose either the “Upload CSV” or “Enter Data” button to
   enter your data in the application. Some sample .csv files are included to utilize the
   upload feature. 
5. After inputting data, select the type of graph you want. You can also name your graph
   in the same window. Select the confirm button. 
6. This window should display the generated graph from your data and the chosen graph type.
   There are also controls for audio playback to hear what the graph sounds like. There are
   also options to change the colors of the graph and to download a PNG of your graph on this page.  
7. To create another graph simply click the “New Graph” button to begin the process again.
